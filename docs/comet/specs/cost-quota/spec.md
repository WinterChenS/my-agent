# cost-quota

## Purpose

支出控制：配额（日/月）＋告警＋超限拦截。

## 设计

- 额度配置：`sys_user` 与 `agent` 各加日/月额度字段（单位与货币跟模型价格一致；空=不限）。
- 校验时机：发起 run 之前按「用户额度 + Agent 额度」检查已用成本（复用审计的按模型价格聚合）。
- 超限行为可配：`BLOCK`（拒绝发起，明确提示）或 `WARN`（仅告警）。
- 前端：顶栏/审计看板显示本日/本月已用成本与额度；≥80% 提示，超限按配置拦截并说明。

## 边界

- 不做阶梯价/折扣/汇率换算（沿用 Phase 15 口径）。
- 不做"事后扣费"式的强制中断（只在发起前检查）。

## 验收标准

- 设置极小额度后连续对话：到限即按配置拒绝（或告警），提示包含已用/额度。
- 审计看板能看到已用成本与额度。
- 未设置额度时行为不变（不拦截）。
