# context-control

## Purpose

让会话上下文**可见且可控**：显示用量、一键压缩、一键清空，避免"上下文爆了只能新建会话"。

## 设计

- 查询接口：返回该会话「当前上下文 tokens 估算 / 压缩触发阈值 / 保留阈值 / 是否已压缩过」。
- 「压缩上下文」：触发官方压缩（`CompactionConfig` 能力）并回报压缩前后用量。
- 「清空上下文」：删除该会话的框架状态（`agent_state` 该 threadId 的行）——**保留聊天记录**，模型从零开始。
- 前端：输入框上方显示用量条（接近阈值变黄、超阈值变红）；两个动作按钮 + 结果反馈。
- 自动压缩发生后，前端提示一次（用户知道发生了什么）。

## 边界

- 不改 token 统计口径（审计不变）。
- 清空上下文不等于删除会话（消息与产物都保留）。

## 验收标准

- 长会话能看到用量与阈值；接近阈值有醒目提示。
- 「压缩上下文」有反馈且用量下降。
- 「清空上下文」后 `agent_state` 无该会话行、聊天记录仍在、随后对话正常。
