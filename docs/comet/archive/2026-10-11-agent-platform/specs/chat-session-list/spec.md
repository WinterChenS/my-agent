# chat-session-list

## Purpose

让左侧会话列表按时间分组，解决「会话一多就变成一长条散列、找不到最近的会话」。

## 设计（D28）

- 分组档位：**今天(0) / 昨天(1) / 最近 7 天(2–7) / 最近 30 天(8–30) / 更早(>30)**，按「相对当天 00:00 的天数差」判定。
- 时间取值：`lastActiveAt` 优先，缺失回退 `createdAt`。
- 边界行为：
  - 今天 00:00 与昨天 00:00 各归本组（不跨天错位）；
  - 未来时间（时钟漂移）并入「今天」；
  - 时间无法解析 → 归「更早」（**不从列表消失**）。
- 只渲染非空分组；组内保持后端返回的原有顺序（后端已按最近活跃倒序）。
- 纯前端渲染层分组：不改后端接口与数据。

## 边界

- 分组不改变会话的排序与筛选逻辑。
- 组标题只是视觉分隔，不参与点击/交互。

## 验收标准

- 左侧会话按上述档位分组显示，每组有标题；空分组不显示。
- 刚聊过的会话出现在「今天」组。
- 跨日边界、时间无法解析、未来时间三种情况的归属与上述一致（单测覆盖）。
- 组内顺序与后端返回顺序一致。
