# 任务 #14 每日科技+AI+GitHub早报(钉钉9点)
# 备份时间：更新为「只走 internet_* 联网工具」之前

任务：生成「全球科技 + AI + GitHub 早报」，中文，发给主人（钉钉单聊）。

一、范围
- 科技/AI 新闻：过去 24 小时；GitHub 周热榜：过去 7 天；GitHub 新项目涨势：近 14 天。
- 只写抓到的真实内容，抓不到就写「未获取到」，严禁编造标题、数字、star 数。

二、抓取（web_search 不可用：TAVILY_API_KEY 未配置；一律用 web_fetch 或 run_command 里的 curl）
1) 科技/AI 新闻源（各取最新若干条即可，不必全抓）：
   - https://techcrunch.com/category/artificial-intelligence/feed/
   - https://techcrunch.com/feed/
   - https://www.theverge.com/rss/index.xml
   - https://openai.com/news/rss.xml
   - https://arstechnica.com/feed/
2) GitHub 每周热榜（本周 star 增长最多）：
   curl -sL -m 40 -A "Mozilla/5.0" "https://github.com/trending?since=weekly" -o /tmp/tr.html
   再用 python3 解析：按 `<article class="Box-row">` 切块，取仓库路径 `<h2[^>]*>\s*<a[^>]*href="([^"]+)"`、描述第一个 `<p>`、本周新增 star `([\d,]+)\s*stars\s*this week`。
3) GitHub 涨势最快（近 14 天新建仓库按 star 排序）：
   curl -s -m 40 --http1.1 -H "Accept: application/vnd.github+json" -H "User-Agent: curl" "https://api.github.com/search/repositories?q=created:%3E<14天前的YYYY-MM-DD>&sort=stars&order=desc&per_page=10" -o /tmp/gh.json
   （必须加 --http1.1，否则响应会被截断、json 解析失败）解析 items 的 full_name / stargazers_count / created_at / description / html_url。
   若 403 限流，退化为抓 https://github.com/trending?since=daily 与 weekly 对比，取日增最快的项目。
   需要更详细的介绍时，可再 curl 该仓库的 README 原始页（https://raw.githubusercontent.com/<owner>/<repo>/HEAD/README.md）取要点。

三、输出结构（每条都给链接，不要输出大表格）
标题：**科技 + AI + GitHub 早报｜YYYY-MM-DD（周X）09:00**
1. 【AI 新闻 TOP5】每条：加粗标题 + 一句要点 + 链接
2. 【科技新闻 TOP5】同上
3. 【GitHub 周热榜 TOP5】每条格式：`n. owner/repo — 本周 +X,XXX★（累计 XX,XXX★）`
   + 介绍（2–3 句中文）：这是什么 / 解决什么问题 / 技术栈或亮点 / 为什么这周这么多人 star。不要只翻译英文 description。
4. 【GitHub 涨势最快 TOP3（近 14 天新项目）】每条：仓库 + 创建日期 + 当前 star + 一句话定位 + 2–3 句介绍与关注理由。
5. 【一句话总结】

四、交付
- 文末列「未获取到的来源」。
- 用 send_im_message 发送；过长就分两条（新闻一条、GitHub 一条）。
