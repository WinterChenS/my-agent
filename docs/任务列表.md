# Agent 平台任务列表（含验收门禁）

> **For agentic workers:** 按阶段顺序执行；每个任务开始前先读《技术方案.md》对应章节；任务完成的判定标准**只有**"验收门禁全绿"，不允许自评跳过。
> 每完成一个任务：`git commit -m "feat(P<阶段>): <任务名>"`。

## 全局约束（每个任务都隐含执行，源自《技术方案.md》第 11 节）

- G1 依赖一致 / G2 分层隔离 / G3 API 契约冻结 / G4 DDL 只进 Flyway / G5 `mvn verify` + `npm run lint && npm run build && npx vitest run` 全绿 / G6 必须附验收证据 / G7 超范围功能进 backlog 不实现 / G8 必须用 AgentScope 官方扩展。
- 环境变量（`.env.example` 提供，本地 `.env` 不提交）：`AGENT_CRYPTO_KEY`、`JWT_SECRET`。
- 提交前 `git status` 必须干净，不得提交 `target/`、`node_modules/`、`.env`。

## Phase 4：AG-UI 聊天主链路（预计 2~3 天，最关键）

### Task 4.1 AgentFactory

**做什么：** 按 agent 配置构建 `HarnessAgent`：sysPrompt、model（由 model → provider 解析出 `provider:model` 字符串）、temperature/max_tokens、Skill（经 skill-postgresql-repository 加载启用的 skill）、MCP（经 `McpClientManager` 注册启用 server 的工具）、权限中间件（映射 `permission_mode`）。配置缓存：配置变更时失效。

**Interfaces（供 4.2/4.3 消费）：**
- `HarnessAgent build(AgentEntity agentConfig)`；`void invalidate(Long agentId)`

**验收门禁：**
- [ ] 单测（Testcontainers + mock 模型端）：给定 DB 配置行能 build 出 agent，绑定 1 skill + 1 MCP 时工具列表包含 MCP 工具（G8：走官方扩展，`grep -r "jsonrpc\|JSON-RPC" src/main/java` 无自研协议解析）
- [ ] 配置更新后 invalidate 生效（修改 prompt → 新会话生效）

### Task 4.2 `/agui/run` SSE 端点

**做什么：** 引入 `agentscope-extensions-agui`，暴露 `POST /agui/run`（SSE）：接收 `RunAgentInput` → 按 `threadId` 定位/创建 `chat_session` → `AgentFactory.build` → 事件流透传 → run 结束把用户消息与 assistant 最终文本落 `chat_message`。支持多 agent 路由（输入中带 agentId 或按 session 关联）。

**验收门禁：**
- [ ] `curl -N -X POST localhost:8080/agui/run -H "Authorization: Bearer $T" -H "Content-Type: application/json" -d '<RunAgentInput JSON>'` 能看到 AG-UI 事件序列（`RUN_STARTED` → `TEXT_MESSAGE_*` → `RUN_FINISHED`）
- [ ] 跑完后 `chat_session`/`chat_message` 有对应行（附 SQL 查询结果）
- [ ] 中途断开 SSE 不抛未捕获异常，服务可继续服务下一个请求
- [ ] G3：端点路径与事件结构未偏离官方 agui 扩展默认行为（对照 agentscope-java `agui.md` 示例）

### Task 4.3 前端聊天页（基础版）

**做什么：** `lib/agui/`：HttpAgent（fetch 注入 Bearer）+ 事件 reducer（事件流→消息树）；ChatPage：左侧会话列表（`/api/sessions`）、右侧气泡流（Markdown 渲染）+ 输入框；历史会话通过 messages 接口回放。

**验收门禁：**
- [ ] 页面发消息 → 流式气泡逐字出现 → 结束后刷新页面历史仍在
- [ ] 网络断开/后端重启时气泡显示错误态且可重试，页面不白屏
- [ ] `npx vitest run`：reducer 单测覆盖 TEXT_MESSAGE_* 与 TOOL_CALL_* 至少各一例
- [ ] G5 全绿；录屏或截图为证
